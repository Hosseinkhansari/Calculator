Calculator
A simple calculator made with HTML, CSS and JavaScript.
Features
• Basic calculations (+, -, *, /)
• Decimal numbers
• Percentage
• Positive / negative numbers
• Backspace
• AC button
• Multiple calculations
• Continue calculating after =
Technologies
• HTML
• CSS
• JavaScript
About
I made this project as a practice project while learning JavaScript.
The main focus of the project was implementing the calculator logic without using eval() and getting more comfortable with JavaScript, DOM manipulation and handling different calculator states.
